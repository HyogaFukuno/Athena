## 中（SG）

### M1 試合を待っている人に贈ったスポンサーの品が消え、ポイントも戻らない（**直した**：SG #53）

- **何が起きるか**：
  - トーナメントで自分の試合を待つ人は、持ち物を預けて観戦者のコンパスだけを持つ（`PlayerReset.bench`）。
  - `/sponsor` は、贈る相手が試合の「プレイヤー」なら、待っている人にも贈れる（`SponsorCommand.buy`、待っているかを見ていない）。
  - 品は、待つ間の空のインベントリに入る（`target.getInventory().addItem`）。
  - 試合に戻るとき、預けた持ち物でインベントリを上書きする（`PlayerReset.unbench`：`inventory.setContents(items[0])`）。贈った品はここで消える。
  - ポイントは贈ったときに減らしていて（`stats.spend`）、戻さない。
- **起きやすさ**：sg2 はデュオのトーナメント（`team-size: 2`、`mode: tournament`）。ライブゲームの終わりから決勝まで、ほとんどの陣営が自分の試合を待つ時間がある（`LiveGameState.java:320`、`DeathmatchState.java:395・480`）。観戦者が多い時間帯でもある。
- **直したこと**：待っている人に贈った品は預かり（`PlayerReset.holdForBench`）、試合に戻るとき（`unbench`）に返した持ち物へ足す。入りきらない分は足もとに落とす。贈られた人には「試合が始まるときに渡る」と知らせる。切断したときは `unbench` を通るので、その品も一緒に預かる。試験：`PlayerResetTest`。

### M2 先に倒れた人が、生き残っている味方に賞金をかけられる（**直した**：SG #53）

- **何が起きるか**：
  - `/bounty` は、かける人が観戦者で、相手が試合のプレイヤーならかけられる（`BountyCommand.request`・`confirm`）。同じチームかは見ていない。
  - デュオで先に倒れた人は観戦者になるので、生き残っている味方にかけられる。
  - 味方が優勝すると、かけた人は 1.5 倍を受け取り（`StatsService.settle` の `sponsorReturn`）、味方は賞金を受け取る（`record.claimBounty`）。P をかけると、チームで 2.5P が戻る。
- **11-16 の M4 との関係**：M4 では、勝ちの見えた終盤にかければ確実に増やせる問題を、「3 チーム以上が残っている間だけ」にして抑えた。味方にかける場合は勝ちが確実ではないが、自分のチームの勝ちに賭けられること自体が、賞金の仕組みの趣旨（ほかの人に懸ける）から外れる。
- **直したこと**：同じチームの相手には、`/bounty` でも `/confirmbounty` でもかけられない（`BountyCommand.onTeammate`）。ソロでは今までどおり。試験：`BountyCommandTest`。

## Athena

- **新しい問題はない**。master は 11-17 から変わっていない。
- **C2（ワールドのスレッドの出入り）は、隙間が実在する**：
  - サーバースレッドの `athenaJoinThread`（`WorldServer.java:1693`）は、スレッドが生きているかを見てから、ワールドをそのスレッドの一覧に足す。
  - ワールドのスレッドの `runLeaves`（`AthenaWorldThread.java:362`）は、最後のワールドが抜けたら `running = false` にして終わる。
  - 「抜けるのを待つ処理（`leave`）が時間切れになる」と「同じスレッドの最後のワールドが抜けた直後に、別のワールドが加わる」が重なると、加わったワールドを誰も tick しない。
  - SG は試合ごとに新しいスレッドを作るので、起きにくい。低のまま。直すなら、加える側と止める側を同じロックで守る。

## 問題がなかった所

- **SG の部屋の持ち主のスレッド**：持ち主を替えるのは、今の持ち主が 1 秒の処理を終えたときだけ（`volatile` の `ownerWorld`）。別のスレッドからの頼みは `Room.execute` で持ち主へ回す。
- **SG が別の部屋の人に呼ぶ `hidePlayer`・`showPlayer`**：Athena は、相手のワールドのスレッドへ回してから追跡を外す（`CraftPlayer.java:1106`）。どのスレッドから呼んでも壊れない。
- **SG の勝敗**：脱落のたびに、残りのチームが 1 つになったかを見る。先に倒れた味方も優勝に入る。相打ちと全員の退出は「勝者なしで決着」。
- **SG のトーナメント**：シードと組み合わせは説明どおり。全員が倒れた陣営は組む前に外す。陣営が奇数なら、いちばん上のシードが戦わずに勝ち上がる。
- **SG の味方の攻撃**：止めている（`GameEventListener.onDamageRule`）。味方にキルの手柄は付かない。
- **SG の切断**：決着したあとに切断中だった人の戦績は、`finish` でまとめて保存する。抜けたままの人の通算は脱落のあとで捨てる。
- **SG の static な共有状態**：あるのは経路探索の予算（同期あり）、`LobbyGc`（同期あり）、ブロックの種類の表（読むだけ）だけ。
- **Athena のマップしたファイル**：置き換えは必ず別名で書いて改名し、チェックサムも確かめる。走っているサーバーの読み出しが壊れる経路はない。
